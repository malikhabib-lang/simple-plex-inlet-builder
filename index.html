Before you use this tool

    
This builder creates sample inlet CSV files for import into Simple Plex Runner. Please note:

    
    
      
  • It is an independent tool and is not an official Bio-Techne or ProteinSimple product. It is not validated or supported by the manufacturer.
    • 
      
  • Check every generated file in Simple Plex Runner before starting a run: analyte names, inlet positions, sample types and dilution factors.
    • 
      
  • Follow your lab SOPs, the kit insert and manufacturer documentation. They take priority over this tool.
    •
